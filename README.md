# 경매 매도가 추정 — Claude Code 프로젝트

## 처음 한 번만 하면 되는 설정

1. 이 폴더를 통째로 압축 풀어서 원하는 위치에 두기
2. `.env.example`을 복사해서 `.env`로 이름 바꾸고, 인증키 채워넣기:
   ```
   MOLIT_SERVICE_KEY=발급받은_인증키
   KAKAO_REST_API_KEY=발급받은_카카오_REST_API_키
   ```
   - `MOLIT_SERVICE_KEY`: [공공데이터포털](https://www.data.go.kr)에서 "연립다세대 매매 실거래가" 활용신청
   - `KAKAO_REST_API_KEY`: [카카오 개발자](https://developers.kakao.com)에서 애플리케이션 생성 후 REST API 키 발급 (가입 즉시 발급, 승인 대기 없음) — 물건 주소를 좌표로 바꿔 반경 기준 비교를 하는 데 쓰입니다.
3. 이 폴더에서 터미널 열고 `claude` 실행해서 Claude Code 켜기

### 더 편하게 켜기 (선택)

매번 터미널 열고 폴더 이동하기 귀찮으면, `start_claude.bat` 파일을 **더블클릭**하면
자동으로 이 폴더로 이동해서 Claude Code를 켜줍니다. 자주 쓸 거면 이 파일을
마우스 오른쪽 클릭 → "보내기" → "바탕화면에 바로가기 만들기" 해두면 편합니다.

## 그 다음부터는 그냥 이렇게 쓰면 됩니다

- **새 물건 분석하고 싶을 때**: "OO빌라 매도가 알아봐줘, 사건번호 OOOO, 주소 OOOO,
  전용면적 OO㎡, N층" 이라고 말하면, Claude Code가 어떤 지역코드/기간으로 API를
  조회해야 하는지 알려줍니다. 그 명령어를 터미널에 붙여넣고 실행하면 됩니다.
- **API 조회 결과가 나오면**: `data/raw/` 폴더에 저장해두면, `estimate_price.py`가
  물건 주소를 좌표로 바꿔서 **실제 반경(기본 400m) 안의 유사면적·유사층 매물만**
  골라 비교합니다 (빌라는 같은 건물 매매사례가 거의 없어서, "동일건물"이 아니라
  "가까운 거리"를 기준으로 비교해요). `CLAUDE.md`에 적힌 규칙에 따라 8절 포맷으로
  매도가 범위(보수적 급매가/현실적 체결가/상단 매도가 등)를 계산해서 보여줍니다.
- **여러 달치를 조회했다면**: 매번 붙여넣어도 되고, `data/raw/` 폴더에 `.xml`
  파일로 저장해두고 "data/raw 폴더에 있는 걸로 계산해줘"라고 하면 한 번에 계산됩니다.

## 알아두면 좋은 추가 기능

- **예쁜 리포트로 보고 싶을 때**: 계산해달라고 할 때 "html로도 만들어줘"라고
  덧붙이면 `reports/` 폴더에 보기 좋은 리포트를 저장하고 자동으로 브라우저로
  열어줍니다.
- **지금 어떤 동네가 뜨고 있는지 궁금할 때**: "동네 랭킹 보여줘"라고 하면
  지금까지 조회해둔 지역들 중에서 가격이 오르고 있거나 거래가 활발한 동네
  순위를 보여줍니다. "역촌동 안에서 소형/중형/대형 비교해줘"처럼 특정 동을
  지정하면 면적 구간별 비교도 함께 보여줍니다.
- **가격이 오르는 중인지 궁금할 때**: 매도가 계산 결과에 월별 평당가 추이가
  자동으로 같이 나옵니다 (`--html`이면 꺾은선 그래프로도 보여줍니다).
- **예상 전세가·전세가율이 궁금할 때**: 전월세 실거래가를 따로 조회해서
  `data/raw_rent/`에 저장해두면, 매도가 계산할 때 예상 전세가(매매가와 동일한
  반경 기준)와 매매 대비 전세가율·갭을 자동으로 같이 보여줍니다.
- **입지가 궁금할 때**: 매도가 계산할 때 자동으로 가장 가까운 지하철역·
  초등학교·마트까지 거리를 같이 보여줍니다.
- **임장 갈 때 근처 중개업소가 궁금할 때**: 서울 물건이면 서울 열린데이터광장에서
  받은 공인중개사사무소 정보 CSV를 `data/brokers_seoul.csv`에 저장해두면 반경
  1km 안 영업중인 곳을 거리순으로 전화번호와 함께 보여줍니다. 경기도 물건이면
  경기데이터드림 API로 같은 동 안의 영업중인 곳을 보여줍니다(거리순 정렬은 안 됨).
- **낙찰가 대비 얼마 남는지 궁금할 때**: "낙찰가 1억200 정도로 생각 중이야,
  수익성도 계산해줘"처럼 낙찰가/입찰예정가를 알려주면 매도가 시나리오별
  예상 순수익·수익률을 같이 보여줍니다.

## 폴더 구조

```
molit-project/
├── CLAUDE.md                  ← 분석 규칙 (자동으로 매 세션 로드됨)
├── README.md                  ← 이 파일
├── .env.example                ← 인증키 설정 예시
├── start_claude.bat            ← 더블클릭으로 바로 Claude Code 켜기
├── scripts/
│   ├── molit_rhtrade_api.py    ← 매매 실거래가 API 호출 스크립트
│   ├── molit_rhrent_api.py     ← 전월세 실거래가 API 호출 스크립트
│   ├── geocode.py               ← 주소 → 좌표 변환 (카카오 로컬 API)
│   ├── lawd_lookup.py          ← 법정동코드 ↔ 구 이름 조회
│   ├── broker_lookup.py        ← 인근 중개업소 조회 (서울 CSV / 경기데이터드림 API)
│   ├── estimate_price.py       ← 반경 기반 매도가·예상 전세가 계산 스크립트
│   └── rank_areas.py           ← 동네 랭킹 / 면적 구간별 비교
└── data/
    ├── raw/                    ← 매매 실거래가 조회 결과(XML) 저장하는 곳
    ├── raw_rent/                ← 전월세 실거래가 조회 결과(XML) 저장하는 곳
    ├── brokers_seoul.csv        ← 서울 열린데이터광장 공인중개사사무소 정보 (직접 저장)
    └── lawd_codes.md            ← 법정동코드 참고표
```
