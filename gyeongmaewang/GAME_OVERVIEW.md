# 🏆 경매왕 — 게임 전체 정리 (조언 요청용)

> 2026-09-25 기준, 현재 버전 v65.
> 금액 단위는 모두 **만원**이다(예: 15000 = 1.5억).
> 코드 식별자(`LF_CHARS` 같은 것)는 필요할 때 참고하라고 적어 둔 것이다.

---

## 0. 한 줄 소개와 조언받고 싶은 점

**한 줄 소개**: 부동산 경매(주로 서울 빌라)를 한 바퀴 돌려 보는 교육용 게임이다.
- 한 바퀴는 **물건 고르기 → 조사(임장) → 밀봉 입찰 → 낙찰/패찰 → 명도(점유자 내보내기) → 수리 → 매도**로 이어진다.
- 여기에 캐릭터 6명의 "경매 투자자로 사는 1년" 인생 시뮬레이션을 얹었다.

**GPT에게 묻고 싶은 것**(원하는 대로 골라 써도 됨)
1. 재미 구조 — 한 판의 긴장감, 반복 플레이 동기, 초반 이탈 지점
2. 교육 효과 — 실제 경매 실무 감각이 제대로 전달되는지, 빠진 핵심 실무가 있는지
3. 밸런스 — 캐릭터 6명, 엔딩 조건, 경제 수치
4. 콘텐츠 확장 — CASE 003 이후, 이벤트, 엔딩
5. 수익화·배포 — 정적 사이트, 회원제, 랭킹 등
6. UI/UX — 정보가 많은 화면을 초보자가 이해하기 쉽게 만드는 법

## 1. 형태·기술

| 항목 | 내용 |
|---|---|
| 형태 | 브라우저 단일 페이지 게임. HTML+JS 한 파일(약 1.6MB)에 외부 라이브러리 없음 |
| 서버 | 필요 없다. 정적 호스팅(예: Cloudflare Pages)에 폴더째 올리면 된다. 계산은 전부 방문자 브라우저에서 한다 |
| 저장 | 기본은 브라우저(localStorage). 설정을 채우면 Supabase 회원·클라우드 저장이 켜진다 |
| 소리 | 음원 파일 없이 브라우저가 즉석에서 합성한다. 캐릭터별 BGM 모티프, 장소별 환경음, 점유자 감정 반응음 |
| 그림 | 2D 애니메이션풍 일러스트 95장 이상(webp). AI 이미지 생성으로 만들었고, 실존 인물은 쓰지 않았다 |
| 글꼴 | 제목은 Black Han Sans·Do Hyeon, 본문은 IBM Plex Sans KR |
| 코드 규모 | JS 약 3.7만 줄. 자동 테스트(Playwright) 100여 개, 밸런스 봇 시뮬레이션 포함 |
| 화면 | 스크롤 없는 게임식 레이아웃: 왼쪽(모바일은 위)은 그림 무대, 오른쪽은 명령 패널. PC와 모바일을 둘 다 지원한다 |

**회원 기능 원칙**
- 받는 정보는 아이디, 비밀번호, 시작한 이유 하나뿐이다. 이름·생년월일·전화·주소·실제 이메일·성별은 받지 않는다.
- 모든 표에 RLS(`user_id = auth.uid()`)를 걸었다. 브라우저에는 공개용(anon) 키만 두고, service_role 키가 들어오면 기능이 스스로 꺼진다.
- "바로 체험하기"는 익명 로그인이다. 가입하면 같은 계정으로 승격돼 기록이 이어진다.
- 이탈 통계: CASE 시작 → 조사 → 입찰 → 낙찰/패찰 → 명도 → 수리 → 매도 → 결과 → 다음 CASE 순서의 퍼널이다.

## 3. 핵심 한 판 — CASE 흐름

### CASE 001: 1992년식 빌라, 최만식 할아버지(68세, 생계 곤란)
- **물건**: 감정가 1.45억, 최저가 1.02억. 중개사는 1.6억이라 말하지만 숨겨진 실제 시세는 1.535억이다.
- **조사**: 행동 16개를 330분 시간 예산 안에서 고른다. 집·현장·재방문 동선에 따라 이동시간이 붙고, 결과는 확률로 드러난다.
- **숨은 위험 4개**: 누전(120), 점유자 말 바꾸기(딸이 열쇠를 가짐), 실거래 착시, 체납관리비(38).
- **입찰**: 밀봉 입찰. 경쟁자 6유형이 72% 확률로 각각 참가하며 최대 5명이다.
  - 흐린 경쟁 신호, 단독낙찰, 2등과의 차이 공개, 정보 출처 배지가 있다.
  - 10%는 한산한 분위기, 8%는 사람이 몰린다.
- **명도**: 행동 9개와 이사비 제안 0~300.
  - 인도명령 10(결정까지 16~21일), 강제집행 350(접수 28일 뒤).
  - "사정 끝까지 들어주기"로 협조도가 오른다(7절).
- **수리**: 최소 90 / 가성비 470 / 부분 210 / 풀 리모델링 1,500.
- **매도**: 호가 4단계. 매수자 5유형에 계약 파기 확률 5~35%.
- **결과**:
  - 입찰·명도·수리·매도 네 부문 등급, 플레이 스타일, 교훈.
  - **💰 사업 결과 등급과 🧠 투자 판단 등급을 따로** 매긴다(원래부터 있었다). 예: "돈은 벌었는데, 다시 하면 위험합니다. 이번엔 운이 판단을 덮어 줬어요."
  - 예상 vs 실제(매도가·수리비·명도기간) 판단 기록, 들은 정보 중 무엇이 맞았나 복기, 실패 도감.
  - v65 추가: **🧭 이번 판 돌아보기** — 입찰 전에 알 수 있던 것 → 내 판단 → 실제로 벌어진 일(알 방법이 없던 사건은 '운'으로 따로 표시, 판단 점수에서 제외) → 다음에 확인할 것.
  - v65 추가: **패찰에도 판단 평가** — 상한을 지킨 패찰은 "좋았어요", 정보 없이 쓴 가격·과한 가격·너무 아낀 가격은 각각 따로 짚는다.

### CASE 002: 은평구 투룸, 정은주 씨(협조형) — 주제는 "멈출 줄 아는 사람"
- **물건**: 감정가 1.87억, 최저가 1.197억, 실제 시세 1.58억.
- **숨은 위험**: 벽 뒤 누수, 엇갈리는 시세, 같은 건물 급매, 매수자 대출이 적게 나옴.
- **갈림길 ①(잔금 전)**: 계속 / 잔금 포기(보증금 10% 몰수) / 업자에게 현 상태로 매각.
- **명도**: 쉽다. 단, 누수를 물으면 거짓말을 한다.
- **갈림길 ②(수리)**: 제대로 520~620 / 최소 수리+고지 150 / 도배로 덮기 120.
  - 덮으면 5주차에 재발하고, 판 뒤 70% 확률로 하자담보 청구 900이 들어온다.

### 경매 게시판 (반복 플레이의 중심)
- 매주 여러 물건이 올라온다. 물건마다 **이번 기일 입찰 / 유찰 노리기 / 관심 / 포기** 중 하나를 고른다.
- 유찰 노리기: 한 번 유찰될 때마다 최저가가 20% 내려간다. 대신 남이 가져갈 수 있고, 싸질수록 사람이 몰린다.
- **함정 물건**(서류만 봐도 피할 수 있다):
  - 선순위 임차인: 보증금 1.2억 인수 → 잔금 포기
  - 1/2 지분: 공유자 우선매수
  - 유치권: 40% 확률로 +1,800, 아니면 −2,600
  - 대지권 미등기: 55% 확률로 +1,400, 아니면 −1,900
- 커리어 물건 등급: 구축 빌라 1.5억 → 3억 → 5억 → 10억 → 꼬마빌딩 20억.

### 세계 반영
- 날씨(맑음·흐림·비·장마·눈·한파·폭염)와 시기(이사철·장마철·휴가철·명절·연말·겨울 비수기)가 실제 수치를 바꾼다.
  - 바뀌는 것: 조사 시간, 누수 단서, 경쟁자 수, 명도 일정, 수리비·기간, 매수 문의.
- NPC 기억: 만난 횟수와 "시세 적중 3/7" 같은 신뢰 기록이 쌓인다.

### 돈 계산
- 취득비는 낙찰가의 1.7%, 중개보수는 min(90, 0.5%).
- 세금: 매매사업자는 종합소득세 누진(6~45%) × 1.1. 비교용으로 1년 미만 보유 양도세 70%.

## 4. ⭐ 인생 모드 — 캐릭터 6명 캠페인

### 기본 틀
- 서윤부터 순서대로 연다: 입문 → 도현(시간) → 미정(사람) → 재훈(집) → 은경(돈) → 태식(경험).
- 어떤 엔딩이든(BAD 포함) 보면 다음 사람이 열린다. 진행이 막히지 않는다.
- 시작일은 2026-03-02. 조사는 입찰 이틀 전부터 한다(서윤과 전업 경로는 3일).
- **거점 화면**: 노트북·휴대폰·달력·책장·침대·냉장고·외출·통장·CASE 파일·벽을 눌러 시간을 쓴다.
- **월 정산**: 수입 − 고정비 − 장비 유지비 − 대출이자(현금이 마이너스면 연 5.5%).
- **체력·스트레스(0~100)**: 스트레스가 높으면 정보 정확도가 떨어지고, 60을 넘으면 이사비 요구가 5% 늘어난다.
- **장비**: 노트북 250(온라인 조사 −12%), 듀얼 모니터 45, 프린터 35, 중고차 1,300(이동 −35%, 월 25).
- **인맥(관계 0~5)**: 김사장(게시판 관심도 공개), 박 중개사(시세 정확도), 박 실장(수리비 −5%·공사 단축), 최 기사(누전 −30%), 법무사(인도명령 5일 단축), 이삿짐 사장(이사비 −10%).
- **거점 이사**: 영등포 사무실(2.5억) → 마포 공유오피스 → 여의도 → 강남 → 내 경매 사무실(10억).
- **칭호**: 첫 낙찰, 단독낙찰러, 하자탐정, 명도협상가, 급매사냥꾼, 손절의 달인, 지역전문가, 전업투자자, 경매왕.
- **생활 이벤트**: 2~4일마다 하나. 절반은 캐릭터 전용이다.
- **몰입 연출**:
  - 거점 소품이 시간 따라 바뀐다(젖은 우산 → 마른 우산, 첫 낙찰 액자, 실수 메모, 쌓이는 서류, 캐릭터 전용 소품).
  - 놓친 물건의 후일담, 지난 실수를 기억하는 혼잣말, NPC마다 다른 전화 받는 습관, 매수자 방문 몽타주.

| 서윤 | 취업 / 전업 |
| 도현 | 회사 유지 / 퇴사(퇴직금 +2,000) |
| 미정 | 가게 직접 / 점장 두기 |
| 재훈 | 현장 일 계속 / 전업 |
| 은경 | 보수적 / 비중 확대 |
| 태식 | 소형 위주 / 젊은 파트너 |

**엔딩 4종** — ⚠ v65에서 바뀜: 예전엔 갈림길을 고르는 순간 엔딩이 났지만(누적 1억에서 갈림길 → GOOD 조건 1.5억에 갈 기회가 없는 문제), 지금은 **갈림길 = 남은 시간을 살 방식 선택**, **엔딩 = 인생 1년 결산 날** 판정이다. 머리줄에 "결산 D-N"이 뜨고, 벽에서 "지금 결산하기"도 할 수 있다. 1년이 다 돼서 갈림길이 오면 고르자마자 결산한다.
- **BAD**: 대출 1억 초과(파산), 누적 적자, 스트레스 85 이상 중 하나.
- **SPECIAL**: 캐릭터별 숨은 조건. 힌트는 벽에 있다.
- **GOOD**: 누적 1.5억 이상 + 스트레스 60 미만 + 손해 CASE가 적을 것.
- **NORMAL**: 그 밖의 경우.

| 캐릭터 | NORMAL | GOOD | BAD | SPECIAL (조건) |
|---|---|---|---|---|
| 서윤 | 반지하의 창문 | 처음 내 이름으로 된 집 | 다시 편의점 알바 | 손해 없는 첫 해 (손해 0으로 3건+) |
| 도현 | 두 개의 명함 | 내 시간을 산 사람 | 번아웃 | 아무도 모르게 (회사 유지 + 연차 5일 넘게 남김) |
| 미정 | 가게와 경매 사이 | 사장님의 두 번째 사업 | 문을 닫은 날 | 전화가 먼저 오는 사람 (관계 4+ 인맥 4명) |
| 재훈 | 서류보다 벽 | 내가 고친 집 | 보이지 않던 하자 | 하자탐정 (칭호 + 현장 유지) |
| 은경 | 초록색 합계 칸 | 숫자가 말해 준 것 | 계산 밖의 비용 | 한 번도 물리지 않은 시트 (보수 + 손해 0, 2건+) |
| 태식 | 오래된 수첩의 새 장 | 아들에게 보낸 사진 | 무릎이 먼저 말했다 | 둘이 가는 길 (파트너 + 스트레스 40 미만) |

- 엔딩 뒤에는 **커리어 모드**가 열린다. 캐릭터마다 자금과 기록을 따로 보관한 채, 엔딩 없이 계속한다.
- 도입부: 선택 화면(능력 별점 6개 + "이 캐릭터의 삶") → EP.0 오프닝(전용 BGM, 타이핑 대사).
- 조건을 채우면 벽에 후일담이 열린다.

### 밸런스 검증
- 봇이 캐릭터당 약 300명분(1년, 3,300~4,100판)을 플레이했다.
- 1년 순수익 평균은 약 9,100이고, 캐릭터 간 차이는 −8.7%(서윤) ~ +4.5%다. 파산 0.
- 낙찰률 40~52%.
- 원칙: 성별이 능력치를 정하지 않는다. 누구도 모든 면에서 최강이 아니다.

## 7. "사정 듣기" (명도의 인간적인 면)

- 실제 명도 현장에서는 점유자가 구구절절 사정을 털어놓는다. 그걸 **다 들어주는 체감**을 넣었다.
- 인물마다 성격에 맞는 긴 사연이 있고, 여러 번에 걸쳐 한 토막씩 듣는다.
  - 예: 억울함 호소, 낙찰자에게 화풀이, 비굴하게 우는소리, 주저리주저리, 치매 초기 할머니가 옆에서 "우리 철수 왔어?"라며 끼어듦.
- 다 들으면 관계가 오르고 버티기가 내려간다. 진짜 원하는 것과 희망 이사비 힌트를 얻는다. 돌봄이 필요한 유형이면 복지 연계 안내가 나온다.
- **표현 원칙**: 노인·외국인·아이·정신건강 문제를 존중해서 그린다. 위기 상황 안내는 112/119/109만 쓴다.

## 8. 설계 원칙 (지켜 온 것)

- 법률 설명은 일반적이고 정확하게 한다. 수치는 게임용 단순화라고 밝힌다.
- 모든 인물은 가상이고 실존 인물 얼굴은 쓰지 않는다. 참고한 학습 자료는 요약·재구성만 한다.
- 초보자용으로 쉬운 말을 쓴다. 정답을 알려 주기보다 "왜 그렇게 되는지"를 결과 화면에서 복기하게 한다.
- 기존 시스템은 지우지 않고 쌓는다.
- 스크롤 없는 게임식 화면, 모바일 지원.

## 8-1. v65에서 GPT 조언으로 바꾼 것

- 갈림길과 엔딩 분리(1년 결산).
- 첫 방문자 첫 화면: 큰 버튼 하나("▶ 첫 경매 시작하기 — 한서윤과 서울 빌라 한 채"), 나머지 메뉴는 "다른 방법으로 시작하기"에 접음, 오른쪽엔 한 판 흐름 5단계 안내. "전체 메뉴 보기"로 언제든 원래 화면.
- 입찰표에 "💰 이 금액이면 묶이는 돈"(낙찰가·취득세·수리비·명도 예비비·석 달 이자)과 "최소 얼마에 팔려야 본전", 내 현금으로 모자라는 대출 금액, "🚪 이번엔 입찰하지 않기" 버튼.
- 필요한 순간에만 기능 소개: 처음 낙찰 → 명도왕 연습 안내, 처음 패찰 → 패찰도 판단이라는 안내, 첫 결과 → 돌아보기·기록 안내.

## 9. 알려진 한계와 다음 후보

1. **CASE가 2개뿐이다**(001·002). 게시판 물건은 자동 생성이지만, 손으로 짠 스토리 CASE를 더 만들지 고민 중이다(상가, 선순위 임차인, 지분, 유치권 등).
2. **AI 협상 채팅**은 독립 버전에서 꺼져 있다. 켜려면 서버리스 함수와 API 비용이 필요하다.
3. **랭킹·소셜 기능이 없다.** 주간 경매 랭킹 아이디어만 있다.
4. **엔딩 그림 12개**가 아직 없다.
5. 연습장(퀴즈·개념 노트)이 게임과 따로 논다. 게임 안으로 자연스럽게 녹일 방법이 필요하다.
6. 수치(시세·경쟁률·세금)는 교육용 단순화다. 현실성과 재미 사이의 균형 조언이 필요하다.
7. 첫 판 튜토리얼 길이, 정보 과부하, 모바일 가독성.
