# 🎨 경매왕 — 남은 그림 발주서 (그림만)

> ⚠️ **이 문서는 그림을 그리기 위한 것이다. 게임 조언·기획 의견은 필요 없다.**
> 아래 프롬프트를 **한 번에 하나씩** 보내면, 그 한 장만 그려 주면 된다.

---

## ⓪ 공통 규칙 (새 대화의 첫 메시지로 먼저 보내기)

```
지금부터 게임 일러스트를 한 장씩 그릴 거야.

[규칙]
1. 메시지 1개 = 이미지 딱 1장. 콜라주·분할 화면 금지.
2. 화풍: 2D 애니메이션 일러스트, 부드러운 셀 셰이딩, 깔끔한 선, 따뜻하고 차분한 영화 조명, 가로 16:9.
3. 핵심 소품은 가운데 60% 안에. 화면 아래쪽 1/4은 비교적 비워 둬.
4. 읽을 수 있는 글자·숫자·로고·간판 금지. 종이·화면은 빈칸이나 색 블록으로만.
5. 배경은 한국 서울의 평범한 동네(빌라·골목). 서양식 집·바다 풍경 금지.
6. 사람은 뒷모습·손·흐릿한 모습으로만(아래에 따로 적은 경우 제외).
이해했으면 그리지 말고 "확인"만 답해.
```

## 1. 인생의 갈림길 — 김태식 (1장)

**첨부:** 김태식 게임 그림을 같이 올리고 보내기.

```
[이미지 1장, 16:9] 첨부한 인물 그대로.
[외모] 68세 남성. 짧게 넘긴 은회색 흰머리, 검은 뿔테 사각 안경, 남색 누빔 조끼, 파랑·흰 체크 셔츠, 카키 바지, 갈색 가죽 가방. 모자·주황 조끼 금지.
목동 아파트 거실. 태식이 소파에 앉아 휴대폰을 들고, 방금 온 메시지(빈 화면)를 읽는다. 한쪽 손은 무릎 위. 탁자에 가죽 수첩과 현장용 가방. 창밖은 오후. 걱정해 주는 가족을 생각하는 복잡하지만 따뜻한 표정. 글자 없음.
```

## 2. CASE 002 장면 (4장 — 인물 없음)

**C1 은평구 투룸 외관**
```
[이미지 1장, 16:9] 인물 없음.
서울 은평구의 평범한 4층짜리 붉은 벽돌 빌라, 맑은 오전. 좁은 골목, 주차된 작은 차 한 대, 화분 몇 개. 3층 창 하나만 커튼이 반쯤 쳐져 있다. 멀리 북한산 능선이 흐릿하게. 간판·번호판 글자 없음.
```

**C2 벽지 뒤 누수 발견**
```
[이미지 1장, 16:9] 인물은 손만.
투룸 안방 벽. 벽지 한쪽을 뜯어 젖힌 자리 아래로 물길 자국과 거뭇한 곰팡이 얼룩. 장갑 낀 손 하나가 벽지 끝을 잡고 있다. 바닥에 손전등과 뜯어낸 벽지 조각. 측면 빛으로 얼룩이 또렷하게. 공포 분위기 없이 사실적으로. 글자 없음.
```

**C3 도배로 덮을까**
```
[이미지 1장, 16:9] 인물 없음.
같은 안방. 얼룩진 벽 앞에 새 벽지 두루마리와 풀통, 롤러. 한쪽엔 견적서처럼 보이는 빈 종이 한 장. "덮어 버릴까, 제대로 고칠까" 망설임이 느껴지는 조용한 구도. 오후 빛. 글자 없음.
```

**C7 매수자 대출이 적게 나왔다**
```
[이미지 1장, 16:9] 앞사람은 뒷모습만.
은행 상담 창구. 젊은 부부의 뒷모습이 흐릿하고, 그 앞 책상 위에 서류 한 장과 펜. 창구 직원은 손만 보인다. 부부의 어깨가 살짝 처져 있다. 차분한 실내 조명. 글자·로고 없음.
```

## 3. 시기 그림 (7장 — 한 세트)

**일곱 장 모두 끝에 이 문장을 붙이기:**
```
세트 규칙: 서울 골목의 같은 빌라 앞, 같은 각도. 계절과 소품만 바뀐다. 인물 없음(멀리 흐릿한 뒷모습만 가능). 가운데 핵심 소품 하나가 또렷하게. 간판·글자·숫자 없음.
```

**G1 이사철**
```
[이미지 1장, 16:9] 봄 오전. 빌라 입구 앞에 이삿짐 상자가 쌓여 있고, 사다리차 팔이 3층 창으로 뻗어 있다. 벚꽃잎이 조금 날린다. 활기찬 분위기.
```

**G2 장마철**
```
[이미지 1장, 16:9] 여름, 굵은 비. 빌라 외벽을 타고 빗물이 흐르고, 1층 창틀 아래 물 얼룩. 입구에 우산 하나가 펼쳐진 채 세워져 있다. 축축하고 무거운 분위기.
```

**G3 휴가철**
```
[이미지 1장, 16:9] 한여름 한낮. 빌라 1층 부동산 유리문이 닫혀 있고 문에 빈 종이 한 장(글자 없음). 골목이 텅 비어 있다. 쨍한 햇빛과 짙은 그림자.
```

**G4 추석 연휴 전후**
```
[이미지 1장, 16:9] 초가을 저녁, 보름달. 빌라 창 몇 개만 불이 켜져 있고, 입구 앞으로 선물 상자를 든 흐릿한 뒷모습이 지나간다. 조용하고 따뜻한 분위기.
```

**G5 설 연휴 전후**
```
[이미지 1장, 16:9] 겨울 아침, 맑고 차가운 공기. 빌라 입구 문고리에 작은 복주머니 장식. 골목은 한산하고 몇몇 창에만 불빛.
```

**G6 연말·연초**
```
[이미지 1장, 16:9] 12월 밤. 빌라 몇몇 베란다에 작은 전구 장식, 골목 가로등 불빛. 1층 창 안으로 책상 위 서류 더미와 달력이 흐릿하게(글자 없음). 바쁘지만 들뜬 분위기.
```

**G7 겨울 비수기**
```
[이미지 1장, 16:9] 한겨울 흐린 오후. 빌라 지붕과 난간에 얇게 쌓인 눈, 골목에 발자국이 거의 없다. 입구 옆 전봇대에 빈 전단 한 장이 바람에 펄럭인다. 조용하고 한산한 분위기.
```

## 4. 연습실 입구 (4장 — 한 세트)

**네 장 모두 끝에 이 문장을 붙이기:**
```
세트 규칙: 따뜻한 실내 조명, 책상 위 정물 구도, 소품 한두 개만 가운데 크게. 인물 없음(손도 없음). 네 장이 같은 책상·같은 빛으로 이어지는 세트처럼. 글자·숫자·로고 없음.
```

**H1 명도 연습**
```
[이미지 1장, 16:9] 책상 위에 현관 도어록 모형과 열쇠 꾸러미, 그 옆에 작은 탁상 달력(칸만 있고 숫자 없음). 달력 몇 칸에 색 동그라미.
```

**H2 협상 연습**
```
[이미지 1장, 16:9] 책상 위에 머그컵 두 개가 마주 놓여 있고, 가운데 말풍선 모양 메모지 두 장(빈칸). 옆에 화면이 켜진 스마트폰 하나(빈 화면).
```

**H3 매도 연습**
```
[이미지 1장, 16:9] 책상 위에 빈 가격표 태그 두어 개와 계산기, 빌라 사진 한 장(빈칸 사진), 도장. 가격표 하나에 빨간 펜으로 동그라미.
```

**H4 시세 맞히기**
```
[이미지 1장, 16:9] 책상 위에 펼친 지도 한 장, 그 위에 빨간 핀 몇 개와 돋보기. 돋보기 아래로 작은 빌라 모양이 크게 보인다. 탐험하는 느낌.
```
