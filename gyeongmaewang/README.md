# 🏆 경매왕 — 독립 게임 버전

낙찰부터 명도·수리·매도까지, 경매 한 사이클을 돌려 보는 게임이다.
원래는 claude.ai의 "권리분석 연습장" 안에 있던 게임인데, **경매왕만 따로 떼어서 어디든 올릴 수 있게** 만든 폴더다.

```
gyeongmaewang/
├── site/            ← 이 폴더만 통째로 올리면 끝 (서버 필요 없음)
│   ├── index.html   게임 전체 (1.6MB, 외부 라이브러리 없음)
│   ├── config.js    ☁ Supabase 연결 설정 (비워 두면 회원 기능 꺼짐)
│   ├── cloud.js     ☁ 회원·클라우드 저장·이탈 통계
│   ├── assets/      그림 95장 (webp, 약 16MB)
│   └── _headers     Cloudflare Pages용 캐시 설정
└── src/             소스 (고칠 때만 필요)
```

## 게임에 들어 있는 것

- **CASE 001·002** — 조사(시간 예산) → 밀봉 입찰 → 개찰 → 명도 → 수리 → 매도
- **📋 경매 게시판** — 매주 여러 물건 중 어디에 돈을 걸지 고른다. 이번 기일 입찰 / ⏳ 유찰 노리기(싸지지만 남이 가져갈 수 있고 사람이 몰린다) / 관심 / 포기. 서류만 보면 피할 수 있는 **함정 물건**(선순위 임차인·지분·유치권·대지권 미등기)도 섞여 나온다.
- **🏢 사무실** — 책상·게시판·서류함(지난 CASE)·연락처·트로피 벽
- **📇 NPC 기억** — 만난 횟수와 "시세 적중 3/7" 같은 기록이 쌓여, 다음 판에 누구 말을 믿을지 정하게 된다
- **🌦️ 살아 있는 세계** — 장소별 환경음(법원 웅성거림·골목·중개사무소 "따랑~"·빈집 물방울), 점유자 감정 반응음(한숨·호통·울먹임), 대사 읽기(브라우저 음성, 기본 꺼짐), 날짜·날씨·시기(이사철·장마·휴가철·명절·비수기)가 조사 시간·누수 단서·경쟁자 수·명도 일정·수리비/기간·매수 문의에 실제로 반영
- **🎲 입찰의 공포** — 흐린 경쟁 신호, 단독낙찰, 2등과의 차이 공개, 정보 출처 배지, 비 오는 날

## 왜 서버가 필요 없나

게임 계산은 **전부 방문자 브라우저에서** 돈다. 서버가 하는 일은 파일을 내려주는 것뿐이라
**정적 호스팅(무료)** 이면 동시 접속이 수천 명이어도 버틴다 — 무료 호스팅 서버가 잠들고
깨느라 수십 초 걸리는 문제(Render 무료)도 없다.

- 저장: 기본은 방문자 브라우저(localStorage). `config.js`를 채우면 아이디로 로그인해서 **다른 기기에서도 이어할 수 있다** (아래 ☁ 참고).
- 소리: 음원 파일 없이 브라우저가 즉석에서 만든다.

## 올리는 법 (추천: Cloudflare Pages)

1. https://pages.cloudflare.com → 가입 → **Create a project → Direct Upload**
2. `site` 폴더를 통째로 끌어다 놓기 → Deploy
3. `xxxx.pages.dev` 주소가 바로 생긴다. 한국 사용자도 빠르다(서울 엣지).
4. (선택) 도메인을 사서 연결 — 예: `gyeongmaewang.kr`

GitHub에 연결해 두면 푸시할 때마다 자동으로 다시 올라간다 — 그때는
"Build output directory"를 `gyeongmaewang/site`로 지정한다(빌드 명령은 비워 둔다).

다른 곳도 똑같이 된다: Netlify(폴더 끌어다 놓기), Vercel, GitHub Pages.

## 독립 버전에서 빠진 것

| 기능 | 왜 | 되살리려면 |
|---|---|---|
| 💬 AI 협상 채팅 | claude.ai 안에서만 되는 기능을 쓴다 | 서버리스 함수 + Claude API 키(사용량만큼 과금) |
| 🎨 그림 관리 | claude.ai 자산 저장소를 쓴다 | 필요 없음 — 그림은 `assets/`에 고정 |
| 권리분석 노트·퀴즈 | 연습장 쪽 기능 | 코드에는 남아 있고 화면에서만 숨겼다 |

## ☁ 회원·클라우드 저장 켜기 (Supabase, 무료)

코드는 다 들어 있다. **설정 파일 한 개만 채우면** 켜진다. 비워 두면 지금처럼 이 기기에만 저장된다.

1. https://supabase.com → 새 프로젝트 (리전: **Northeast Asia (Seoul)**)
2. **Authentication → Sign In / Providers**
   - Email: 켬 · **Confirm email: 끔** (가짜 이메일을 쓰므로 메일 확인을 하면 가입이 안 끝난다)
   - **Allow anonymous sign-ins: 켬** ("바로 체험하기"용)
3. **SQL Editor** → `src/schema.sql` 통째로 붙여넣고 Run
4. **Project Settings → API** 에서 두 값을 복사해 `site/config.js`에 넣는다
   - `url` ← Project URL
   - `anonKey` ← **anon public** 키 (또는 `sb_publishable_...`)
   - ⛔ **service_role / sb_secret_ 키는 절대 넣지 않는다.** 넣으면 코드가 스스로 회원 기능을 끈다.
5. 다시 올리기(Deploy). 끝.

### 어떻게 동작하나

| | |
|---|---|
| 받는 정보 | 아이디(영문 소문자·숫자·_ 4~16자) · 비밀번호 · 시작한 이유 1개. **이름·생년월일·전화·주소·실제 이메일·성별은 안 받는다** |
| 아이디 처리 | `<아이디>@users.kyungmaewang.local` 가짜 이메일로 바꿔 넣는다. 화면에는 절대 안 보인다 |
| 바로 체험하기 | 익명 로그인. CASE를 하나 끝내면 "다른 기기에서도 이어하시겠어요?" → 아이디를 만들면 **같은 계정이 승격**돼 기록이 그대로 이어진다 |
| 저장 | 게임이 저장할 때마다 1.5초 모아 올린다. 왼쪽 아래 표시: ☁ 저장됨 / ☁ 저장 중... / ⚠ 오프라인 |
| 오프라인 | 이 기기에는 계속 저장되고, 연결되면 밀린 것을 올린다 |
| 처음 로그인 | 이 기기 기록을 계정으로 옮긴다. 다른 기기에서 로그인하면 계정 기록을 받는다 |
| 보안 | 표 3개 모두 RLS: `user_id = auth.uid()` 본인 것만. 이벤트 표는 **쓰기만** 된다 |
| 이탈 통계 | CASE 시작→조사→입찰→낙찰/패찰→명도→수리→매도→결과→다음 CASE. 퍼널 조회 SQL은 `schema.sql` 맨 아래 |

⚠ **비밀번호를 잊으면 복구가 어렵다** — 이메일을 안 받기 때문이다. 가입 화면에도 적혀 있다.
(관리자는 Supabase 대시보드 Authentication → Users에서 해당 사용자의 비밀번호를 재설정해 줄 수는 있다.)

⚠ 가입할 때 "가입 설정 문제로 막혔어요"가 뜨면 Confirm email이 켜져 있거나, Supabase가 이메일 도메인을 거절한 것이다
→ `config.js`의 `emailDomain`을 `users.example.com` 같은 형식으로 바꿔 본다(이미 만든 계정은 옛 도메인이라 그대로 두어야 한다).

### 저장 구조에 대해

진행·업적·도감·NPC 기억·통계·설정을 **`saves.state` 한 문서(jsonb)** 에 통째로 넣는다. 표를 여러 개로 쪼개면
"돈은 저장됐는데 업적은 안 됨" 같은 반쪽 저장이 생긴다. 주간 랭킹처럼 **남의 기록을 모아 보는 기능**이 필요해질 때
그 부분만 별도 표로 뺀다.

## 나중에 붙일 것

- **이번 주 경매 랭킹**: 공개용 표 하나(점수만) + 읽기 정책.
- **AI 협상 채팅**: 서버리스 함수에 Claude API 키(브라우저에는 절대 두지 않는다).

## 고치고 다시 만들기

```
cd src
python3 merge.py                               # 소스 → rights-study.html (연습장 번들)
python3 build_standalone.py ../site            # 번들 → 독립 버전
```
⚠️ `build_standalone.py`는 그림을 `_blob/<id>` 에서 복사한다. 이미 `site/assets/<id>.webp`에
있으므로, 새 그림을 넣을 때만 `_blob/`에 같은 이름으로 넣어 주면 된다.

테스트(`src/tests/`)는 Playwright로 로컬 서버(`srv.py`, 8765)를 띄워 돌린다.
`t49.js`는 가짜 Supabase로 두 기기를 흉내 내 회원·저장·오프라인·RLS 흐름을 검사한다(빌드 결과를 8790에서 띄운 뒤 실행).
