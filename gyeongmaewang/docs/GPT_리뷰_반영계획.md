# GPT 설계 리뷰 반영 계획

GPT 리뷰의 핵심: "사건은 24개인데 공략이 하나(조사 최대 → 사정 듣기 → 합의서 → 가성비 수리 → 적당한 매도)로 수렴할 위험".
→ 모드·캐릭터·사건을 늘리지 않고, 기존 사건마다 '무엇을 확인하고 무엇을 포기할지'를 다르게 만든다.

## ✅ 1차 반영 (v125)
| 항목 | 내용 |
|---|---|
| 정답 누설 제거 | 예상 수익 칸의 "모르는 위험 N개" → "아직 안 해 본 조사 N개" / 상단 "숨은 위험 1/3 발견" → "찾아낸 위험 N개" / 예상 손익이 숨은 실제 시세 대신 내 시세 감으로 계산 |
| 서류는 확률로 못 읽지 않는다 | 서류로 확인하는 인수 사실(비고란 등)은 조사하면 항상 확인됨 |
| 입찰 포기 평가 | 근거 있는 철수 👍 / 잘 피했지만 근거 없음 🍀 / 지나치게 조심 🤔 / 확인 없이 넘김 ⚠️ — 포기해도 무조건 좋은 점수가 되지 않음. 이 물건의 숨은 비용·남는 선을 그때 공개 |
| 매도 제안 = 조건 묶음 | 가격 + 예상 잔금일 + 조건(대출 승인·수리 요구·부모님 확인 등) + "실제로 남는 돈". 역제안에 "잔금일 당기기", "수리 대신 가격 조정" 추가. 사정을 들으면 그 매수자가 양보할 수 있는 조건을 알려 줌 |
| 낙찰 ≠ 소유권 | 낙찰 화면에 매각허가결정 → 대금 납부(소유권 취득) → 인도명령(6개월 안) 표시 |
| 법률 문구 | 강제집행 겁주기 문구를 "겁주기(법적 절차 아님)"로 / 당해세 사건: 법정기일·확정일자·2023년 개정 반영 / 외국인 사건: "국적이 아니라 한 가지 열람으로 단정한 게 위험" / 저감률·유찰 기간은 게임용 단순화 표시 / 지역농협·회원수협 = 상호금융(은행과 구분) / 세후 수익은 "가정 아래 세금 예시" |

## ✅ 2차 반영 (v126) — 첫 세 사건마다 '막힌 곳'이 다르다
| 사건 | 막힌 곳 | 시간으로 푸는 길 | 다른 길 |
|---|---|---|---|
| 담배는 주머니에만 | 믿음 — 협조도 95여도 날짜 얘기가 안 됨 | 신분·절차 설명 → 약속한 날 다시 연락 | 따님 연결(조사로 알아내야 열림) |
| 서류 한 장과 이삿날 | 날짜 — 배당기일 전엔 새집 잔금을 못 치름 | 배당기일 뒤로 이삿날 맞추기 | 이사비 100만원 선지급(돈). 확인 안 하면 이삿날에 "못 나가요"로 밀림 |
| 스물한 살의 보증금 500 | 생활 — 갈 곳·이삿짐 옮길 방법 | 주말에 직접 같이 옮기기(이틀) | 용달 예약(35만원) |
- 첫 '사정부터 듣는다'가 무엇이 막혔는지 알려 준다(협조도만 오르는 게 아니라 질문이 풀림)

## ✅ 4차 반영 (v128) — 한 번만 · 이어하기
- 버그: 매도 수락을 빠르게 여러 번 누르면 매각대금이 여러 번 입금됐다(실측 3번) → 수락·수리·호가·입찰·명도·이사비 제안을 '그 단계일 때만, 한 번만' 처리
- 사건 도중 새로고침·창 닫기 → "▶ 이어하기" 카드. 난수 사용 위치까지 저장해 새로고침으로 운을 다시 굴릴 수 없음
- 낙찰 뒤엔 "접기" 불가(실제로도 잔금 미납 = 보증금 몰수) · 입찰 전이면 기록 없이 접기 가능

## ✅ 5차 반영 (v129) — 읽은 대사는 빠르게
- 대사창: 이미 읽은 문장은 타자 효과 없이 한 번에
- 사연 듣기: 읽은 줄엔 '읽음' 표시 + "⏩ 읽은 대사 넘기기"(다음 안 읽은 줄에서 멈춤 — 새 정보는 못 건너뜀)
- 대출 카톡: 전에 끝까지 들어 본 상담사는 대화가 한 번에(첫 상담 약 6초 → 약 0.1초)

## ✅ 6차 반영 (v130) — 캐릭터마다 한 수 하나 + 약점 하나
| 캐릭터 | 한 수(판마다 한 번) | 약점 |
|---|---|---|
| 서윤 | 🔗 자료 엮기 — 확인할 게 남은 조사를 짚음(사실은 안 알려 줌) | 현장 조사 +20분 |
| 도현 | 🗓️ 묶어서 예약 — 다음 전화·온라인 조사 2건 절반 시간 | 현장 이동 +30분 |
| 미정 | 🤝 조건 묶음 제안 — 협조도↑·요구액 −15% | 나흘 안에 합의서 없으면 신뢰 −15 |
| 재훈 | 🔧 직접 손보기 — 가장 큰 하자 수리비 절반 | 사흘 소요 |
| 은경 | 📊 자금 버티기 표 — 보유기간별 이자·남는 현금 | 조사 시간 40분 |
| 태식 | ☎️ 옛 인맥 — 실제 거래선 이야기 | 60분 · 10만원, 한 사람 의견이라 확인 필요 |

## ✅ 7차 반영 (v131) — 증거 카드 3종 + 밸런스 봇 4종
- 조사로 연 카드마다 📄 자료상 확인 · 🔍 추정 · 🗣️ 당사자 주장 + **출처** + **아직 모르는 점**
  - 하자는 항상 '추정'이고 수리비는 범위(×0.7~1.5)로 — 뜯어 봐야 확정
  - 시세·관리비는 '당사자 주장' — 같은 광고를 보고 한 말 두 개는 독립 확인이 아니다
  - 예전 ✅확정/🟡추정 표시는 이 세 갈래로 대체(안 연 칸은 ❔미확인만)
- 밸런스(`tests/t_balance.js`, 결과 `docs/밸런스_리포트.md`): 입문자·숙련자·완주형·무리 4종을 22개 물건에
  - **발견한 버그**: 입찰표 안전/균형/공격 구간이 고정 800/700/300만원 여유 + 비용 이중 계산 → 17억짜리 건물에서 '안내대로 쓰면 손해'
  - 여유를 가격 비례(9%/5%/2%)로, 부대비용 3%로 바꿈
  - 결과: 완주형 12낙찰 11흑자·최악 −441만 / 숙련자 +1.8억 / 입문자 −1.6억(인수·대형 사건에서 손실) / 무리 −13.3억

## ✅ 8차 반영 (v132) — 입찰 직전 '모르는 비용' 경고
- 입찰표·봉투 화면에 경고 상자(`bidwarn.js`). 판단 근거는 **플레이어가 볼 수 있는 것만** — 사건 제목(선순위·당해세·유치권·통건물·리스), 안 해 본 조사 목록, 물건 크기
  - 🚨 제목에 위험이 적혀 있는데 권리 확인(명세서 정독·전입일 표·계약서 대조 등)을 안 했으면: 할 조사 목록 + 빼 둘 '모르는 비용 여유'(매도가의 %) + 봉투에서 **"모르는 채로 쓴다" 체크 전엔 제출 불가**, "🔍 조사하러 돌아가기" 버튼
  - 큰 물건은 "예상이 5%만 빗나가도 N만원"을 같이 보여 줌
- 덤으로 고친 것: 은경 계산기가 "아직 모르는 위험 N개"(숨은 정보 — 탐지기가 됨)를 말하던 걸 "안 해 본 조사 N개"로
- 밸런스 봇에 **경고를 따르는 입문자** 추가: 입문자와 같은 조사만 하다가 🚨가 뜨면 거기 적힌 확인만 함
  - 입문자 12낙찰 6흑자 −1.6억 → **9낙찰 9흑자 +2.6억, 최악 +1,307만**
  - f53은 확인 후 인수금액을 알고 포기, f61·f64·f54는 손실 → 흑자
- 리포트에 투입 현금(대출 없음 가정)과 **투입 대비 최악 손실률** 추가 — 입문자 26%, 무리 25.6%(10% 이상 날린 판 14번), 경고 따름 0%

## ✅ 9차 반영 (v133) — 패찰 뒤 판정 버그 + 자금 흐름
- **버그**: 패찰·포기 판정 기준선(시세×0.78)이 떠안는 돈(인수·관리비)을 빼지 않았다. 6,000만원 인수가 있는 f53을 최저가에 쓰고 진 사람에게 "조금 더 써도 남는 가격이었어요 — 아쉬워요"라고 했다(실제론 최저가도 손해)
  - 기준선에서 떠안는 돈을 뺀다(`frTakeOver`). 커리어 판정의 '입찰가 절제'도 같은 기준으로
  - 기준선이 최저가보다 낮으면: "떠안을 돈 때문에 최저가에 써도 남기 어려웠어요 — 입찰하지 않는 게 정답"
- 패찰 화면 1등 가격 설명을 세 칸으로: 한계선 초과 / **공격 구간(제일 잘 팔려야 남음 — 운에 기대는 거래)** / 균형 구간 안(따라가도 남았을 가능성). 예전엔 공격 구간도 "따라가도 남았을 수 있어요"라고 해서 조심한 사람을 괜히 아쉽게 만들었다
- 입찰표에 **💼 자금 계획**: 입찰보증금 · 낙찰되면 필요한 돈 · 지금 현금 → 대출 필요액 · 한 달 이자(연 5% 가정). 현금이 보증금보다 적으면 "실제론 입찰 자체를 못 한다"
- 자금 흐름 봇(`tests/t_leverage.js`, `docs/자금흐름_리포트.md`) — 현금 1억으로 22개를 순서대로
  - 현금만 신중파: 3개만 입찰 가능 → 1.14억
  - 대출 신중파(최저금리): 21개 입찰·12낙찰·11흑자 → **3.55억**
  - 한도 끝까지 무리파: 13낙찰 2흑자 → **13판 만에 −434만, 이후 9판 보증금도 없음**
- 패찰 흐름 점검: 패찰 화면은 이미 "이 가격이면 어떤 거래였나"·남은 것·다음 물건 버튼이 있어 새로 만들지 않고, 틀린 판정만 고쳤다

## ✅ 10차 반영 (v134) — 중개사 시세 전화 복구 + 보증금 신용대출
- **버그(플레이 중 제보)**: 중개사 시세 전화가 명세에 '시세 함정'이 적힌 물건에만 있어서 22개 중 12개(도현 f22·f23, 미정 전부 등)에선 시세를 물어볼 방법이 없었다
  - 함정이 없는 물건엔 평범한 "☎️ 중개사 3곳 전화(시세)"를 채운다 — 세 곳 중 둘은 실제 시세 근처, 하나는 광고 호가 기준(🗣️ 당사자 주장)
  - 시세 단서가 다른 조사로만 나오던 f13·f52·f63엔 중개사 전화를 따로(덜 확실하게, 55%)
  - 명세 원본은 건드리지 않는다(물건을 다시 열어도 조사가 늘지 않음)
  - 전화하면 시세 범위가 좁아진다(예: f22 ±11% → ±5%). 조사 완주형 봇 11낙찰 **11흑자**(이전 12낙찰 11흑자, 최악 −441만 → +725만)
- **보증금 신용대출**(`credit.js`, 커리어 모드): 현금이 입찰보증금보다 적으면 봉투에 못 넣는다(실제 경매와 같다). 대신
  - 🏛️ 은행 6.5%(1,500만·심사 1시간) / 🏦 저축은행 13.9%(2,500만) / 💳 카드론 15.5%(1,000만), 합계 4,000만까지 — 게임용 표본
  - 모자란 만큼만 빌린다. 패찰하면 "보증금 돌려받았으니 바로 갚기"(한 주치 이자만)
  - 낙찰되면 빚을 안고 가고, 매도까지 걸린 날만큼 이자가 보유비에 붙는다
  - 한도로도 안 되면 "빌릴 곳이 없어요 — 보증금이 작은 물건을 고르세요". 주간 도전 모드는 제한 없음
- 자금 흐름 봇 재실행: 무리파는 이제 보증금이 한도를 넘는 7판에서 입찰 자체를 못 한다

  - 물건 전용 점유자 11명(`npc_occ_물건_표정`) — 지금 '노년 남성'·'험한 인상 남성' 같은 유형 공용 그림이거나 다른 이야기용 그림(f31 구혜란: 모피 숄 체납자 그림이 미용실 원장 자리에). 12명은 이미 사연에 맞는 전용 그림
