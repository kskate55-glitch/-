# GPT 조언 요청 — "교육적인데 지루하다" (v216)

자동 플레이로 잰 수치(사건 7개 × 꼼꼼/대충 전략, 24개 사건 버튼 구성 비교)를 넣은 질문 프롬프트.

- 한 사건 평균 클릭 ~25번, 클릭당 화면 텍스트 ~500자
- 사정 듣기 독백 사건당 ~36줄(선택지 없음)
- 명도 버튼 24개 사건 중 23개가 같은 6개
- 조사 버튼 ~10개 중 5개는 모든 사건 동일
- 꼼꼼한 전략 7/7 이익, 대충 전략은 적자 또는 명도 막힘 → 정답 루트가 사건마다 같음

프롬프트 전문은 대화에 코드 블록으로 붙였다(같은 내용).
