# 🏆 경매왕 — 게임 전체 요약 + 조언 요청

> 아래는 제가 만들고 있는 웹 게임 **〈경매왕〉** 의 현재 상태 전체 요약이에요.
> 읽어 보시고 **① 더 재미있게 ② 더 완성도 있게** 만들 방법을 조언해 주세요.
> 맨 아래에 구체적인 질문을 정리해 뒀어요.

---

## 1. 한 줄 소개

부동산 **법원 경매**(주로 빌라·다세대)를 **조사 → 입찰 → 대출 → 잔금 → 명도(점유자 내보내기) → 하자 수리 → 매도**까지 한 사이클로 직접 해 보는 **스토리형 경영 시뮬레이션**이에요.
정답 맞히기 퀴즈가 아니라, **정보를 모으고 · 사람을 읽고 · 위험을 계산해서 마지막에 얼마 남았는지**로 평가받는 게임이에요.

- 형태: 브라우저 단일 HTML 웹 게임(PC·모바일), 픽셀아트 캐릭터·배경, 합성 효과음·BGM
- 대상: 경매에 관심 있는 입문자~중급자. 재미로 하다 보면 권리분석·명도·매도 감각이 생기게 하는 것이 목표
- 모든 사건·인물은 가상. 법률 설명은 일반 원칙 수준(실제 입찰은 서류·전문가 확인 전제)

## 2. 전체 구조

```
첫 화면(홈)
 ├─ 📖 스토리 (메인) ─ 6단계 캠페인: 캐릭터 6명 × 에피소드 4개 = 24판
 ├─ 🗂️ 케이스 상자 ─ 풀린 단계의 물건을 자유롭게 다시 플레이
 ├─ 📋 경매 게시판 ─ 이번 주 물건 목록(진짜 물건 + 함정 물건), 유찰 노리기
 ├─ 📅 이번 주 경매 ─ 모두가 같은 물건·같은 경쟁자로 겨루는 주간 도전
 ├─ 🧪 연습실 ─ 명도왕(명도 협상 미니게임)·협상 연습·매도 연습·시세 맞히기
 └─ 📊 기록 · 📖 도감(점유자 31종) · 🏅 업적(20개)
```

### 스토리 = 캐릭터의 "방"에서 진행
- 캐릭터마다 자기 방(반지하 원룸, 오피스텔 등)이 있고, 그 안에서 시간이 흘러요(날짜·체력·스트레스·현금).
- 방에서 책상(경매 검색·공부), 쉬기, 외출(임장), 통장, 벽(칭호) 같은 행동을 해요.
- 에피소드가 오면 방에 **📱 새 알림 카드**가 뜨고(끌어서 위치 이동 가능), 누르면 한 판이 시작돼요.
- 한 판이 끝나면 방으로 돌아오고 몇 달이 흘러 다음 에피소드가 와요.
- 4판을 끝내면 **판단 점수 평균**으로 엔딩(NORMAL / GOOD / BAD / SPECIAL)이 정해지고 다음 캐릭터가 열려요.
- 6단계를 다 끝내면 **엔딩 크레딧**(모든 역할 "쥬루", "이 사건들은 모두 가상의 사건입니다", 신나는 엔딩곡, 구석에 made by 쥬루).

## 5. 한 판의 흐름 (핵심 게임 루프)

### ① 조사 (입찰 전 — 시간 예산 5시간 30분)
- 📱 집·전화(짧고 얕게) / 🏠 집 컴퓨터(서류는 정확) / 🏚️ 현장(길고 깊게, 이동시간 있음)으로 나뉜 행동을 골라요. **다 할 수는 없어요.**
- 조사하면 확률적으로 **숨은 위험**이 드러나요: 하자(누수·곰팡이·배선), 체납관리비, **인수금액**(선순위 임차인 보증금 등), 유치권·가장임차인 다툼의 근거, 도와줄 사람(가족·고용주·상인회장…), 점유자 속사정, 시세 착시, 같은 건물 급매, 매수자 대출 문제.
- 드러난 건 **📁 사건 파일**(증거 카드)과 **📒 조사 노트**(주인공 옆에 뜨는 손글씨 스프링 공책, 끌어서 이동)에 쌓여요.
- 조사 효율(적은 시간에 중요한 걸 찾았는지)도 평가해요.

### ② 입찰
- 기일입찰표에 금액을 써서 **봉투에 넣기**(도장 쾅) 또는 **입찰 안 하고 유찰 기다리기**.
- 입찰표 옆에 실시간으로: 한글 금액, 예상 세전 수익 범위(모르는 위험이 많을수록 넓게), 보수·균형·공격 구간, "이 금액이면 묶이는 돈", 본전 매도가.
- **최저가 = 감정가 × (1 − 그 법원 저감률)^유찰 횟수**
  서울 전 법원·의정부 본원·남양주·수원 본원·평택 등 20%, 인천·부천·고양·안산 30%.
- 경쟁자 3~6명(초보 과입찰러, 실수요자, 전문 투자자, 저가형, 인테리어 업자…)이 각자 성향대로 써요. 개찰 화면에서 순위가 한 줄씩 올라와요.

- **취득세 등**: 주인공은 매매사업자, 다음 물건을 살 땐 이전 물건을 이미 판 상태(= 무주택 → 1주택 취득)로 가정.
  주택 6억 이하 1% + 지방교육세 0.1% = **1.1%**(85㎡ 초과면 농특세 0.2% 추가, 6~9억 구간은 사이 세율, 9억 초과 3.3%),
  상가·숙박·공장 등 비주택 **4.6%**. (매매사업자라도 주택 수 기준 취득세 중과 판정은 똑같이 받는다는 전제)

### ③ 대출 (낙찰 후)
- 현금이 모자라면 필수, 넉넉하면 "대출 받으시겠습니까? 예/아니오".
- 대출상담사 명함 3장(농협·수협·신협·새마을금고 등 2금융권, 가끔 금리 높고 한도 큰 캐피탈) → 누르면 **카카오톡 스타일 상담 대화**(말풍선이 하나씩 옴) → 조건 비교표 → 선택.
- 이자는 보유 기간만큼 쌓이고, 팔 때 중도상환수수료가 빠져요. (게임용 예시 조건 15종)

### ④ 명도 (보스전)
- 점유자와 대화: 🙇 사정부터 듣기 / 🏛️ 주거지원 같이 알아보기 / 📞 도와줄 사람 연락(조사로 찾아야 열림) / 📅 이사 날짜 정하기 / 📝 합의서 / 📮 내용증명 / ⚖️ 인도명령 / 😤 강제집행 경고 / 🚚 강제집행
- 협조도·버티기 수치, 이사비 흥정, **이삿날 말 바꾸기**(합의서 안 쓰면 +50만원 요구), 하루하루 이자·관리비.
- **🙇 사정 끝까지 듣기**를 누르면 점유자마다 따로 쓴 사연이 한 줄씩 나와요(겉사정 → 속마음). 다 들으면 협조도↑.
- 점유자 말투 5종(존댓말형·거친형·어르신·외국인·장사하는 사람) + 물건마다 고유 대사.
- 5·6단계 **유치권·가장임차인 다툼**: 조사로 근거(점유 개시일, 무상거주확인서, 전입일 등)를 쥐었으면 싸고 빠르게, 모르고 들어가면 수천만 원·몇 달.

### ⑤ 하자·수리
- 빈집을 열면 조사로 알았던 하자는 "🔍 미리 알았음", 몰랐던 건 "😱 몰랐음".
- 인테리어 4안: 최소 수리 / 매도용 가성비 / 풀 리모델링 / 전략적 일부 — 많이 쓴다고 무조건 남지 않아요.

### ⑥ 매도
- 🗣️ **동네 중개사 김사장 얘기 듣기** → 이 동네 실제 계약선 힌트
- 호가 4단계 중 선택 → 매주 매수자 제안(매수자 10종, 얼굴·사연 있음, **사정을 들으면 역제안이 더 잘 통함**) → 수락 / 역제안 / 기다리기 / 호가 내리기
- 계약 직전 파기(대출 최대한도형은 잘 깨짐)

### ⑦ 결과
- 비용표(낙찰가·취득세·이사비·법적 절차·수리·인수금액·이자·중개수수료) → 세전 순이익·수익률
- 세금: 매매사업자(종합소득세) vs 개인(단기 양도세) 비교
- 등급 4개(입찰·명도·수리·매도 S~C), 숨은 위험 발견 수, 조사 효율, 플레이 유형(공감형 명도마스터·냉정한 숫자사냥꾼·법대로·직진 압박·현장조사 탐정)
- "이렇게 했다면" 팁, 가장 잘한 판단 / 가장 비싼 실수, 만난 사람들 크레딧, 오늘의 교훈

## 6. 그 밖의 시스템
- **커리어 자금**: 1억 5천으로 시작 → 판마다 세후 수익이 쌓여 10억 목표, 자산 구간 칭호(구축 빌라 → … → 꼬마빌딩)
- **경매 게시판**: 진짜 물건 + 함정 물건 4종(선순위 임차인, 1/2 지분, 유치권 신축, 대지권 미등기). 서류를 안 보고 입찰하면 크게 당함. "⏳ 유찰 노리기"로 다음 주 더 싸게(대신 사람이 몰림)
