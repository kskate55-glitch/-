# bg_realtor(부동산 사무소 배경) 재생성 프롬프트

현재 그림(`site/assets/7a5df7a4….webp`)은 1280×720이지만 작은 원본을 키운 것이라 뭉개져 있고, 사진풍이라 다른 일러스트와 톤이 다르다.
쓰이는 곳: 본편 중개사 상담 배경, 외전 J01·M01 3장, `bg_broker_office` 별칭.
사람 그림(중개사·주인공)이 이 위에 따로 서므로 **사람 없는 빈 사무소**로 만든다.

```
한국 동네 공인중개사 사무소 내부의 배경 일러스트. 사람은 한 명도 없는 빈 사무소.
정면에 큰 유리 출입문과 통창, 창에는 매물 안내 종이가 격자로 여러 장 붙어 있지만 전부 글자 없는 빈 종이(색 띠와 네모 칸만).
창밖으로 오래된 빌라와 상가가 있는 골목, 늦은 오후의 따뜻한 햇빛이 비스듬히 들어와 바닥에 창틀 그림자가 길게 진다.
왼쪽 벽: 나무 선반에 서류 바인더(색만 있고 글자 없음)와 파일 상자, 큰 화분 하나. 벽에 동네 지도 액자(선과 색 구역만, 글자 없음).
가운데: 나무 상판 상담 책상 하나, 책상 위에 닫힌 노트북, 서류 몇 장, 볼펜, 머그컵. 책상 앞 손님 의자 두 개, 뒤쪽 사무용 의자 하나.
오른쪽: 정수기, 작은 소파, 낡은 캐비닛.
구도: 16:9 가로, 눈높이 정면에서 살짝 비스듬히. 화면 가운데 1/3은 인물이 설 자리라 복잡한 소품을 두지 않고 차분하게. 화면 아래 1/4은 대사창이 올라가므로 바닥과 책상 앞면만.
화풍: 따뜻한 흙빛(갈색·앰버·올리브) 팔레트의 레트로 2D 애니메이션 게임 배경 일러스트, 깔끔한 선화와 부드러운 셀 채색, 영화 같은 부드러운 조명과 약한 공기감. 사진풍 아님.
품질: 고해상도로 선명하게(가로 1920px 이상), 흐림·뭉개짐·노이즈·픽셀 깨짐 없이.
금지: 사람, 글자, 숫자, 간판 글씨, 로고, 실제 브랜드, UI, 말풍선.
```
