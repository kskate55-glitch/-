# 브금 구성 (v213)

모든 음악·효과음은 음원 파일 없이 브라우저(WebAudio)에서 즉석 합성한다(`src/feel.js` 합성기). v213부터 `src/bgmvar.js`가 그 위에 변주를 얹는다.

## 무엇이 달라지나

| | 전 | 후 |
|---|---|---|
| 본편 사건(조사·법원·명도·수리·매도·결과) | 캐릭터·사건과 상관없이 같은 8곡 | **캐릭터 6종 편곡 × 사건마다 다른 화음 진행** |
| 멜로디 | 없음(화음 쪼개기 반주만) | 캐릭터 테마 선율(`GX_MOTIF`)로 시작하는 멜로디가 한 바퀴 부르고 한 바퀴 쉰다 |
| 오프닝 | 캐릭터 곡 | 같은 곡 + 멜로디 |
| 엔딩 에필로그 | 오프닝 곡 그대로 | **판정별 4종** — SPECIAL(한 음 올려 종소리) · GOOD(밝게) · NORMAL(차분하게) · BAD(단조·느리게) |
| 거점(낮·밤) | 공통 | 캐릭터 편곡 |
| 외전 | 에피소드별 편곡(그대로) | 그대로 |

## 캐릭터 편곡

| 캐릭터 | 느낌 | 조성 | 빠르기 | 반주 악기 | 멜로디 악기 |
|---|---|---|---|---|---|
| 한서윤 | 로파이 | 원조 | ×0.92 · 스윙 | 전자피아노 | 전자피아노 |
| 이도현 | 시티팝 | +2 | ×1.06 | 튕기는 소리 | 사각파 |
| 윤미정 | 밝은 어쿠스틱 | −3 | ×1.02 | 튕기는 소리 | 삼각파 |
| 박재훈 | 셔플 | −5 | ×0.96 · 강한 스윙 | 사각파 | 삼각파 |
| 최은경 | 재즈 | +3 | ×0.9 · 스윙 · 7화음 · 걷는 베이스 | 전자피아노 | 종소리 |
| 김태식 | 옛날 드라마 | −2 | ×0.88 | 삼각파 | 삼각파 |

사건마다 화음 진행은 물건 번호로 정해진다(같은 사건은 늘 같은 곡). 명도 곡의 긴장 레이어(저음 드론·심장박동)는 변주 곡에서도 그대로 작동한다.

## 미리듣기

오른쪽 위 🔊 소리 설정 → **🎧 브금 들어보기**에서 캐릭터·장면(오프닝 / 거점 / 조사 / 법원 / 명도 / 수리 / 매도 / 결과 / 엔딩 4종)을 골라 ▶. **🔀 다른 사건**은 같은 장면의 다른 사건 버전, ■은 원래 곡으로 돌아간다. 미리듣기 중에는 화면이 바뀌어도 90초 동안 곡을 유지한다.

## 끄기

`BV_ON = false` 면 예전 곡 그대로 돌아간다. 게임 수치(가격·확률·시간)는 이 파일과 무관하다.
