# v218 예상 깨기 (surprise.js)

지루함의 원인: 같은 순서(조사 전부 → 사정 듣기 → 지원 → 날짜 …)가 모든 사건에서 먹혔다.
개그 대사를 얹는 대신 **상황 자체가 사건마다 다르게 굴러가게** 했다. ★1 사건(첫 판)은 흔들지 않는다.

## ① 흔들리는 출처
- ★2~3 사건은 사람에게 묻는 조사 1개, ★4~5는 1~2개가 '헛방'이다(사건 시드로 결정 — 같은 사건은 항상 같다).
- 빈손: 관리실 "거기요? …잘 모르겠는데요." / 중개사 "저흰 그런 건 잘 안 봐서요~ 호호." / 옆집 "…누구세요? 안 사요." / 은행 "담당자가 오늘 휴가라서요…"
- 옛날 얘기: 친절한데 기준 시점이 불분명하다("그건 전 주인 때 얘긴가?"). 노트에 ⚠️(기준 시점 불명)으로 남는다.
- 헛방이면 숨은 정보를 얻지 못하고, **'🔁 다른 사람에게 다시 확인'** 행동이 열린다(시간이 더 든다).
- 배우는 것: 조사 버튼에 정답이 있는 게 아니라, 이 말이 **언제 기준이고 얼마나 믿을 만한지**가 중요하다.
- 게임 난수(K.r) 순서는 바꾸지 않는다 — 원래 조사를 그대로 돌린 뒤 결과만 되돌린다(테스트로 고정).

## ② 문을 닫는 점유자
- 유형별 확률(사건 시드): 가장임차인 80% · 기세형·유치권 70% · 욕심형 50% · 화난형 40%.
- 사정 듣기 → "무슨 사정을 들어요. 법대로 하세요." 협조도가 오히려 떨어지고 사연 장면이 없다.
- 인도명령을 넣으면 약 일주일 뒤 먼저 전화: "저도 나갈 생각은 있는데요. 이사 갈 집 계약금이 없습니다."
- 새 선택지 **💵 계약금 일부 선지급 + 퇴거일 확정(합의서)** — 선지급 대신 남은 이사비가 약 60%로 줄고, 협조도가 최소 60으로 올라 날짜 합의가 가능해지며 합의서가 작성된다.

## ③ 개찰 희비극
- 150만원 이내 차이 2등: 옆자리 아저씨 "…20만원 차이네. 아깝네요." → [🙅 말 걸지 마세요] → "…네."
- 150만원 이내 차이로 낙찰: "뒤에서 누군가 '아…' 하는 소리가 들렸다."
