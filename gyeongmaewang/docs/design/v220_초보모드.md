# v220 초보 모드 (easy.js)

피드백: "초보자한테 너무 어렵다 — 뭘 눌러야 할지 모르겠고 내용(용어)도 어렵다."
게임 규칙·숫자·난수는 하나도 안 바꾼다. 보이는 것만 바꾼다.

- **처음 한 번 묻기**: "경매, 해 본 적 있어요?" → 🐣 처음이에요 / 해 봤어요. ☰ 메뉴에서 언제든 켜고 끈다. (`kcRec().ez`)
- **🧭 지금 할 일**: 헤더 바로 아래 한 줄. 단계마다 무엇을 하는지 쉬운 말로(조사 단계면 찾은 위험 수·남은 시간까지).
- **⭐ 추천**: 지금 눌러 보면 좋은 버튼 1~2개에 노란 테두리 + "⭐ 추천". 접힌 묶음(조사 도크)이면 묶음 제목에도 ⭐.
  - 조사: 할 수 있는 조사 중 정보가치가 높은 순 → 다 했으면 입찰표·봉투
  - 명도: 선지급 요청 > 🧩 막힌 곳 푸는 버튼 > (협조도 45+) 이사 날짜 > 사정 듣기 > 주거지원 > 가족 > 인도명령. 이사비 제안은 원하는 금액 안팎. 합의 뒤엔 합의서 → 기다리기
  - 수리: 전략적 일부 / 가성비 · 호가: 시세 근처 · 매도: 호가의 96% 이상이면 수락, 아니면 역제안·기다리기
- **📖 용어 풀이**: 말소기준권리·대항력·배당·인도명령·명도·유치권·최저매각가격·입찰보증금·유찰·확정일자·잔금·호가 등 29개. 점선 밑줄을 누르면 한 줄 설명(화면당 단어별 첫 번째만).

검증: ⭐ 추천만 따라 누르는 봇으로 사건 22개를 끝까지 — 모두 결과 화면(또는 패찰)까지 도달.
테스트: `src/tests/t_v220.js` (전체 사건: `EZIDS=f11,f12,...,f64`)

## v221 한서윤 첫 물건 = 튜토리얼
- 조건: 한서윤으로 시작해서 아직 끝낸 사건이 0건인 첫 물건(주간 경매 모드 제외). 이때는 초보 모드 설정과 상관없이 자동으로 켜진다.
- 단계에 처음 들어갈 때마다 🎓 **선배의 한마디** 카드가 한 번씩(사건 소개 → 조사 → 입찰 → 낙찰/패찰 → 명도 → 수리 → 호가 → 매도 → 결과, 9단계). "알겠어요 👍"로 닫는다.
- 두 번째 물건부터는 튜토리얼 없음(초보 모드를 켠 사람만 한 줄 안내·⭐ 계속).
- ☰ 메뉴 "🎓 튜토리얼 그만 보기"로 언제든 끌 수 있다.
- 브라우저 자동화(테스트) 환경에서는 `window.EZ_TUT_FORCE`가 있을 때만 켜진다 — 기존 테스트가 코치 카드에 막히지 않게.
테스트: `src/tests/t_v221.js`
