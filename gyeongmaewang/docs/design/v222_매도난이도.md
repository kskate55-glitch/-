# v222 매도 난이도 낮추기 (saleeasy.js)

피드백: "게임이니까 매도도 좀 더 쉽게."
실측(사건 22개 × 8판 × 호가 2종, `src/tests/simsell.js`)으로 제일 답답한 건 **계약 파기** — 팔릴 때까지 평균 0.4~0.56번.

| 바꾼 것 | 값 |
|---|---|
| 매수자 유형별 계약 파기 확률 | × 0.4 (대출 문제가 숨은 물건의 +12%는 교육용이라 그대로) |
| 흥정 폭(flex) | × 0.5 — 제안가가 시세에 더 가깝고 역제안 성공률(0.5 − 흥정폭×8)이 오른다 |
| 제안 없는 주에 손님 한 명 더 | 25% → 안 팔린 주가 길어질수록 최대 60% (별도 난수, 시세보다 10% 넘게 비싸면 없음) |

| 호가 · 물건 | 파기 평균 전→후 | 8주 넘게 걸림 전→후 | 체결가/시세 전→후 |
|---|---|---|---|
| 살짝 높게 · ★1-3 | 0.39 → 0.15 | 30% → 9% | 0.983 → 0.991 |
| 살짝 높게 · ★4-5 | 0.22 → 0.09 | 16% → 9% | 0.987 → 0.992 |
| 시세 근처 · ★1-3 | 0.51 → 0.21 | 3% → 0% | 0.972 → 0.973 |
| 시세 근처 · ★4-5 | 0.56 → 0.17 | 2% → 0% | 0.974 → 0.974 |

(정책: 호가 97% 이상이면 수락 · 아니면 역제안 1번 · 8주부터 4주마다 300만원 인하)
교훈(첫 주 낮은 제안, 대출 한도형 매수자, 호가 욕심)은 그대로 — 덜 자주, 덜 아프게.
