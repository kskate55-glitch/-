## 3. 실무 조작 · 노트 · 본편 연결

- **해금**
  - `EP_PLAN` 기준으로 매핑했다. 각 캐릭터 1번째 사건은 `res[0]`, 3번째 사건은 `res[2]`의 기록이 생기면 방에 "새 이야기" 알림이 뜬다.
  - 알림에는 지금 읽기 / 나중에 읽기만 있다. 자동 재생은 하지 않는다.
- **사건 결과 분기:** 12편 모두 도입부에서 그 사건의 실제 기록으로 흑자 / 적자 / 패찰·미거래를 가른다. 기록이 없는 금액을 지어내지 않는다.
- **조작**
  - 입력: 첫 입력은 타이핑 중인 문장을 완성하고, 다음 입력이 다음 줄로 간다. Enter·Space·클릭을 받는다.
  - 중복 방지: 두 번 눌러도 한 줄만 넘어간다. 버튼 클릭은 진행으로 새지 않는다.
- **읽기 기능**
  - 기록(백로그): 읽기 전용이다. 선택이나 계산을 다시 실행하지 않는다.
  - 자동 읽기: 선택지·자료 화면·창이 열려 있으면 멈춘다.
  - 설정: 글자 속도 네 단계(즉시 포함), 자동 간격, 소리 끄기를 고른다.
  - 장면 목록: 읽은 장면만 다시 고를 수 있다.
  - 💾 나중에 계속: 장면 id와 버전으로 이어 읽는다. 대본이 바뀌면 그 장면 처음부터 읽는다.
  - 건너뛰기: 건너뛴 뒤에도 노트를 볼 수 있다.
  - 📚 다시 보기: 읽기 전용이다.
- **실무 조작 화면**
  - 종류: 분류(sort), 대조(pick), 가정 바꿔 보기 계산표(calc), 자료 보기(doc).
  - 어느 화면이든 '설명 보고 진행'이 가능하다. 틀려도 불이익이 없고, 본편 돈과는 무관하다.
- **실무노트:** 편마다 3장이다.
  - 맨 위에 '교육용 가상 사례 · 기관·전문가 확인' 한 줄이 붙는다.
  - 참고자료 링크는 노트 맨 아래 접이식에만 있다. 대사에는 URL이 없다.
- **돈·시간 분리**
  - 외전·노트·기록을 여는 동안 현금·게임 날짜·체력·스트레스·사건 비용이 바뀌지 않는다. 12편 × 3갈래 모두 테스트로 확인했다.
  - 본편 시간은 행동할 때만 흐르는 구조라, 따로 멈출 실시간 타이머는 없었다.
- **D01 연습사건:** 물건번호 2 / 218,700,000원과, 오기 초안 1 / 281,700,000원을 대조한다. 본편 입찰 상태에는 옮겨지지 않는다.
- **본편 대리입찰(도현 2번째 사건부터)**
  - 선택 위치: 봉투 확인 화면에서 '직접 참석 / 대리입찰'을 고른다.
  - 대리입찰 검토표: 사건, 금액, 보증금(따로 묶임), 이용료 15만원("밸런스용 가상 이용료·실제 서비스 요금 아님"), 맡기는 범위, 게임상 취소 규칙을 보여준다.
  - 청구 시점: 📮 제출 때 입찰 실행 id마다 한 번만 청구한다.
    - 낙찰이면 사건 비용의 법무·수수료 줄에 더한다.
    - 패찰이면 통장에서 뺀다.
    - 다시 쓰기·입찰 포기는 0원이다.
  - 현금 부족: 대리입찰 버튼이 꺼지고 이유가 나온다. 직접 참석은 그대로 할 수 있다.
  - 시간 효과: 직접 참석은 반차(또는 스트레스)를 쓴다. 대리입찰은 반차를 쓰지 않는다.
  - 결과 불변: 같은 시드·같은 금액이면 참석 방식이 경쟁자 금액과 결과를 바꾸지 않는다.
- **C01 후일담:** 도현 2번째 사건의 실제 기록이 있을 때만 열린다.
  - A: 대리 + 낙찰, B: 대리 + 패찰, C: 직접 참석, D: 입찰 안 함.
  - 기록이 없는 예전 세이브에서는 열리지 않는다(결과를 지어내지 않는다).

- **사용자 첨부 파일:** 작업 폴더에 없었다. 원고의 요약만 반영했다.
  - 대상 파일: 기일입찰표·셀프등기 HWP, 셀프등기 XLSX, 온비드 매뉴얼 PDF, 2017 국유재산 PDF.

- **대본 작성자가 표시한 '전문 검토가 필요한 문장':** 주요 항목을 요약했다. 모두 일반론 또는 '해당 기관 확인'으로 썼다.
  - S01: 간이과세 배제 업종 목록, 사업자등록 신청 시기, 주택 공급 부가세 면세 요건

## 7. 알려진 제약

- **'나중에 읽기':** 이번 접속에서만 알림을 숨긴다. 다시 접속하면 읽지 않은 외전 알림이 다시 뜬다(의도된 동작).
- **모바일 상단 도구줄:** 좁은 화면에서는 가로로 밀어서 봐야 한다. '나중에 계속' 버튼이 화면 오른쪽 밖에 있을 수 있다.
- **대리입찰 범위:** 이도현 스토리 에피소드만 해당한다. 자유 인생 모드·주간 도전·다른 캐릭터에는 없다.
- **D01의 도입 문장:** "정산표에 N만원 남았다"의 N은 에피소드 기록의 손익(만원)이다.
