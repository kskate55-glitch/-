# 〈경매왕〉 캐릭터 오프닝·엔딩 확장 — 작성 명세

작업 폴더: `/tmp/claude-0/-home-user--/faa03bfd-a6ff-592d-9719-8bb7d66ebf18/scratchpad/study`
너는 캐릭터 한 명(또는 지정된 인원)의 **오프닝**과 **엔딩 에필로그** 대본을 데이터 파일로 쓴다.
출력 파일: `study/oe_<id>.js` (예: `oe_seoyun.js`). **다른 파일은 절대 고치지 않는다.** merge.py·빌드도 돌리지 않는다.

## 게임 구조(바꾸지 않는다)
각 캐릭터: **오프닝 → 사건1 → 사건1 후 실무 외전 → 사건2 → 사건3 → 사건3 후 실무 외전 → 사건4 → 엔딩**.
본편 사건 4개, 외전 2편, 점수·자금·세금은 그대로다. 이번 작업은 오프닝(사건1 앞)과 엔딩(사건4 뒤)의 감정선만 강화한다.
- 오프닝이 끝나면 캐릭터의 방(생활 화면)으로 가고, 거기서 사건1 알림이 뜬다. 그래서 오프닝의 **마지막 장면은 "처음으로 경매를 검색/알아보는 순간"** 이어야 하고, 사건1(아래 표)로 자연스럽게 이어질 여지를 남긴다(사건1 물건을 오프닝에서 확정적으로 보여 줄 필요는 없다).
- 엔딩은 4사건이 끝난 뒤(약 1년~1년 반 후) 판정(normal/good/bad/special)에 따라 나온다. 엔딩 에필로그는 **공통부(core)** + **판정별 마무리(normal/good/bad/special)** 로 구성된다. 공통부는 어떤 판정이 나와도 말이 되게 쓴다(성공/실패를 단정하지 않는 회고·태도 변화). 판정별 마무리는 기존 엔딩 제목·문구·그림과 이어지게 쓴다.

## 파일 형식 (그대로 따를 것)
```js
/* oe_<id>.js — <이름> 오프닝·엔딩 (자동 검사: node ../oe/check.js oe_<id>.js) */
OE_DATA.<id> = {
  opening: [ SCENE, SCENE, ... ],          // 9~13장면, 대사 줄 합계 60~90줄
  ending: {
    core:    [ SCENE, ... ],                // 3~5장면, 대사 22~40줄
    normal:  [ SCENE, ... ],                // 1~2장면, 대사 5~12줄. 마지막 장면 art:["@end"] 필수
    good:    [ ... ], bad: [ ... ], special: [ ... ]   // 같은 규칙
  },
  art: [ ART, ... ]                         // 새 그림 슬롯 정확히 4개: 오프닝 3 + 엔딩 1
};
```
SCENE:
```js
{ art:["oe_<id>_op1","op_<id>_1"],   // 이 장면 배경 그림 후보 — 앞에서부터 있는 첫 그림을 쓴다. 새 슬롯 → 기존 슬롯 순서로 폴백 가능
  bg:"bg_base_sillim",                // 최후 폴백 배경 키(아래 목록 중 하나, 필수)
  amb:"room|rain|in",                 // 환경음(선택): "room|clear|in", "room|rain|in", "office|clear|in", "site_night|clear|out", "house|clear|in", "broker|clear|in", "empty|clear|in"
  sfx:"message",                      // 효과음(선택): message, door, key, reveal, chime, knock, paper, coin, stamp
  pos:"50% 50%",                      // 그림 초점(선택)
  ui:{...},                           // 화면 속 소품(선택, 아래)
  uiPos:"low" | "right",              // 소품 위치(선택)
  beats:{ 3:["op_<id>_1_2"] },        // (선택) N번째 대사(1부터)에서 그림을 한 번 바꾼다 — 기존 중간컷 재활용용
  lines:[ [null,"나레이션"], ["서윤","대사"], ["서윤(속마음)","속마음"], ["엄마(전화)","통화 대사"] ] }
```
- 한 줄은 한두 문장. 80자 넘기지 않는다(말풍선 한 칸).
- 화자 표기: 주인공은 이름만(서윤/도현/미정/재훈/은경/태식). 속마음은 `이름(속마음)`. 전화는 `엄마(전화)`처럼.
- 엔딩 판정별 마지막 장면의 `art`는 `["@end"]` 한 개(기존 엔딩 그림을 쓴다는 뜻). 그 장면 대사는 그 그림과 어긋나지 않게.
- 엔딩 core의 한 장면은 새 슬롯 `oe_<id>_end1`을 `art` 첫 후보로 쓴다.

ui 소품(글자는 게임이 그린다 — 그림엔 글자가 없다):
- `{type:"chat", from:"엄마", rows:[["엄마","밥은 먹었어?"],["나","응 먹었어"]]}` — 메신저
- `{type:"search", q:"경매 초보", rows:["검색 결과 한 줄","두 번째 줄"]}` — 검색창
- `{type:"note", t:"제목", rows:["메모 1","메모 2"]}` — 메모/달력/수첩/일정표
- `{type:"bank", t:"₩1,230,000", s:"설명"}`, `{type:"phone", rows:[["항목","+금액","up"|"down"]]}`, `{type:"sheet", rows:[["칸","값"]]}`, `{type:"pos", t:"오늘 매출 ₩..."}`, `{type:"login", t:"오류 문구"}`, `{type:"listing", t:"물건명", a:"감정가 …", b:"최저가 …"}`

ART(새 그림 슬롯 4개):
```js
{ id:"oe_<id>_op1", use:"opening", title:"한서윤 오프닝 — 채용 결과 앞에서 멈춘 밤",
  scene:"한국어 장면 설명(누가/어디서/무엇을/빛·분위기, 2~4문장)",
  reuse:"없으면 대신 쓰는 기존 그림: op_seoyun_1",   // 사람이 읽는 설명
  prompt:"GPT 이미지 생성 프롬프트(한국어). 아래 프롬프트 규칙 준수" }
```
id 규칙: 오프닝 `oe_<id>_op1`, `oe_<id>_op2`, `oe_<id>_op3`, 엔딩 `oe_<id>_end1`. **네 개 모두 대본의 어느 장면 art에 첫 후보로 실제로 쓰여야 한다.**

### 프롬프트 규칙(GPT 이미지 생성용 — 복사해서 바로 넣는다)
- 첨부 전제: "첨부 1 = 주인공 참고 이미지, 첨부 2 = 화풍 참고 이미지(기존 사건 일러스트)". 주인공 외 조연은 첨부하지 않으므로 **조연의 나이·체형·머리·옷을 프롬프트 안에 구체적으로 묘사**한다.
- 캐릭터 단독 시트가 아니라 **배경과 상황이 있는 장면 일러스트**.
- **글자·숫자·UI·말풍선·로고·브랜드 없음**(화면·간판·서류는 빈칸 또는 흐릿한 선).
- **가로 16:9**. 흙빛(따뜻한 갈색·앰버·저녁빛) 레트로 2D 게임 일러스트, 기존 사건 일러스트와 같은 선·채색.
- **화면 아래쪽 1/4은 대화창이 덮으므로** 중요한 얼굴·손·소품을 아래에 두지 않는다(인물은 화면 중·상단에).
- 실존 인물 얼굴, 실존 브랜드, 유명 캐릭터 금지.
- 끝에 한 줄: "16:9 가로, 글자·말풍선 없이 장면만."

## 문체 규칙(가장 중요)
- **설명문 금지, 장면으로 보여 준다.** 반복되는 행동, 짧은 대화, 속마음, 소품(통장·메신저·달력)으로 감정이 드러나게.
- 오프닝은 "썰을 읽는 느낌" — 며칠·몇 주에 걸친 장면 전환, 시간 표기("화요일 새벽 5시 40분", "그 주 금요일") 활용.
- **불행 포르노 금지**: 가난·병·실패를 전시하지 않는다. 캐릭터는 버티고, 농담도 하고, 자기 방식이 있다. 플레이어가 "불쌍하다"가 아니라 "이 사람이 왜 경매를 붙잡는지 알겠다"가 되게.
- 돈에 미친 사람으로 만들지 않는다. 경매는 대박이 아니라 "처음으로 스스로 파고들어 볼 수 있는 길/내 경험을 다시 써 볼 자리"로 다가온다.
- 오프닝에서 실무 강의 금지(권리분석·세금 설명 X). 경매라는 단어를 처음 듣고/검색하고/막막해하는 정도까지.
- 엔딩: 인생 대역전·강남 건물주 금지. **태도·감정·일상의 작은 변화**로 닫는다. bad도 비참하지 않게 — 배운 것과 다음 한 걸음.
- 사투리/말버릇은 기존 캐릭터 유지(재훈: 경상도 말투 "~아이가, 마", 태식: 노년 남성 반말·"허허").
- 금지어(쓰지 말 것): 평공, 텐엑스, 쌤, 강사, 카페, 아카데미, 수강생, 세연, 모닝콜, 두꺼비, 유튜브, http, 010-, 부경꾼, 경장인, 로빈, 이시훈, 박진규, 행꿈사, 열린, 푸디, 회계사님. 욕설 금지. 실존 브랜드·기업명 금지(대기업 이름 X — "회사"). 위기 전화번호는 112/119/109만.
- 성별로 능력을 정하지 않는다.
- 숫자(월급·월세·잔액 등)는 상식적 범위에서, 아래 캐릭터 기본값과 모순되지 않게.
