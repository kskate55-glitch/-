# 캐릭터 오프닝·엔딩 (v211)

구조: **오프닝 → 사건1 → 사건1 후 실무 외전 → 사건2 → 사건3 → 사건3 후 실무 외전 → 사건4 → 엔딩**

이번 판은 **오프닝**과 **엔딩(에필로그)** 두 칸만 바꿨다. 가운데 사건·외전·자금·세금·판정은 손대지 않았다.

| 파일 | 내용 |
|---|---|
| `OPENINGS_ENDINGS.md` | 여섯 명의 오프닝·엔딩 대본 전문 (자동 생성) |
| `ASSET_LIST.md` | 새로 필요한 그림 24장 + 기존 그림 재활용 표 (자동 생성) |
| `IMAGE_PROMPTS.md` | 새 그림 24장의 GPT 이미지 프롬프트, 복사해서 바로 붙여넣는 코드 블록 (자동 생성) |
| `oe_manifest.json` | 장면별 그림 후보·배경·대사 수·새 슬롯 목록 (자동 생성) |
| `AUTHORING_SPEC.md` | 대본 작성 규칙(형식·분량·금지 사항) |
| `gendocs.js` | 위 네 파일을 대본 데이터에서 다시 만드는 스크립트 |

## 어디에 무엇이 있나

- 대본 원본: `src/oe_<캐릭터>.js` (`OE_DATA.<캐릭터> = {opening, ending:{core,normal,good,bad,special}, art}`)
- 연결: `src/story_oe.js`
  - **오프닝**: `LF_OPENINGS`를 새 대본으로 바꾼다. 연출기(`cine.js`)와 SKIP·자동 넘김은 기존 그대로다.
  - **엔딩**: 네 번째 사건 뒤 `epFinish`가 원래대로 판정·저장·다음 단계 해금·엔딩 카드를 끝낸 **뒤에**, 그 카드 위에 에필로그(공통부 + 판정별 마무리)를 덮어 튼다. 끝나거나 SKIP하면 밑의 카드가 드러나고, 카드에서 "🎬 에필로그 다시 보기"로 다시 볼 수 있다.
  - `OE_EPILOGUE = false`면 에필로그만 꺼진다.
- 그림: 장면마다 `art` 후보를 **앞에서부터 있는 첫 그림**으로 쓴다(새 슬롯 → 기존 op_* 그림 → 배경).
  - 새 그림 24장을 넣기 전에도 화면이 비지 않는다.
  - 엔딩 마지막 장면(`"@end"`)은 기존 엔딩 그림 4장을 그대로 쓴다.

## 문서 다시 만들기

```
cd src && node ../docs/story/gendocs.js ../docs/story
node tests/check_oe.js oe_mijeong.js   # 대본 형식 검사
```

## 받은 그림 (연결 완료)

| 슬롯 | 상태 |
|---|---|
| `oe_seoyun_op1` · `op2` · `op3` · `end1` | ✅ 연결 (`src/story_oe.js`의 `OE_ART`) |
| `oe_dohyun_op3` · `end1` | ✅ 연결 |
| `oe_mijeong_op1` · `op2` | ✅ 연결 |
| 도현 op1·op2 · 미정 op3·end1 · 재훈·은경·태식 각 4장 | 대기 — 기존 그림·배경이 대신 나온다 |

새 그림을 받으면 자산 저장소에 올리고 `OE_ART`에 `슬롯 이름: 자산 id` 한 줄만 추가하면 된다.
