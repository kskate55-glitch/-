- op_taesik_1 (김태식 오프닝 — 장면 1 시작): 아침, 목동 오래된 아파트 거실. 오래된 TV에서 뉴스가 혼자 켜져 있고(화면 글자 없음), 태식이 소파에 앉아 신문과 부동산 전단 뭉치를 넘긴다. 베란다 너머 아파트 단지, 창가에 화분 여러 개. 햇살이 거실 바닥에 길게 눕는다.
- op_taesik_2 (김태식 오프닝 — 장면 2 시작): 같은 거실. 태식이 휴대폰을 귀에 대고 허허 웃으며 한쪽 눈썹을 올린다. 탁자 위 전단에 빨간 펜 동그라미(글자 없음). 여유 있지만 날카로운 눈.
- op_taesik_3 (김태식 오프닝 — 장면 3 시작): 작은 서재 방. 오래된 데스크톱 앞에서 태식이 안경을 이마에 올리고 난감해한다. 모니터엔 로그인 창과 빨간 경고 칸(글자 없음). 책상 위 스피커폰 모드 휴대폰 화면에 손녀 사진 아이콘. 살짝 코믹한 분위기.
- op_taesik_4 (김태식 오프닝 — 장면 4 시작): 같은 서재. 태식이 의자를 바짝 당겨 앉아 화면 속 빌라 사진을 가만히 본다. 안경을 코에 걸치고 턱을 쓰다듬는 신중한 얼굴. 창밖 오후 빛.
